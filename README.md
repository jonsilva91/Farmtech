# 🌱 FarmTech Solutions

Projeto acadêmico desenvolvido na FIAP com foco em agricultura de precisão, sensoriamento ambiental e automação via ESP32. Dividido em fases para acompanhamento evolutivo.

## 📚 Estrutura por fases

Este repositório está organizado da seguinte forma:

- 📁 [Fase 01](Fase_01/Cap01/README.md): Modelagem inicial, requisitos e proposta do sistema
- 📁 [Fase 02](Fase_02/Cap01/README.md): Criação do banco de dados relacional (MER/DER)
- 📁 [Fase 03](Fase_03/Cap01/README.md): Integração com ESP32, leitura de sensores, dashboard interativo, API climática
- 📁 [Fase 04](Fase_04/README.md): Aprimoramento do Banco de Dados, Modelos ML para previsão de Irrigação e Fertilização, dashboard interativo para treinamento do modelo
- 📁 [Fase 05](Fase_05/README.md):
  - **Entrega 1 (ML):** EDA do dataset `crop_yield.csv`, **clusterização (tendências)**, e **5 modelos de regressão** para prever rendimento (t/ha) com validação e métricas.
  - **Entrega 2 (Cloud):** Estimativa de custos na **AWS** (São Paulo x N. Virginia) para hospedar API + ML; justificativa técnica considerando acesso aos dados e restrições legais.
  - **Notebook:** [Jonas_rm561465_pbl_fase5.ipynb](Fase_05/src/notebooks/Jonas_rm561465_pbl_fase5.ipynb).
  - **Vídeos (não listados):** links no README da Fase 05 (Entrega 1 e Entrega 2).
